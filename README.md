# Mingle

Mingle is a social networking platform designed to connect users, allowing them to communicate, share media, and manage groups seamlessly. The application features a user-friendly interface and robust functionality, making it an ideal space for social interaction and community building.

## Features

- **User Authentication**: Secure login and signup functionality using PassportJS and bcryptjs to protect user data.
- **Real-Time Messaging**: Engage in real-time text messaging and image sharing, allowing users to stay connected with friends and groups.
- **Group Management**: Create and manage groups for different interests, enabling users to engage in global chats and discussions.
- **Profile Management**: Comprehensive account settings for users to customize their profiles and manage interactions with other users.

## Tech Stack

- **Frontend**: React, Tailwind CSS
- **Backend**: Express.js, Node.js
- **Database**: MongoDB
- **Cloud Storage**: Cloudinary for image hosting
